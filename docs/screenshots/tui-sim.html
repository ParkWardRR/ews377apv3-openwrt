Install Paths
A UART + u-boot (serial cable)
Proven, safest. Requires USB-to-serial adapter on header J2.
LOW RISK
B SSH + ubiformat (no cable)
Mirrored from WAX218 method. Not yet hardware-tested on EWS377.
UNTESTED
C Web UI upload (per-SKU image)
Download the .bin matching your SKU (282/284/300). Persistence unconfirmed.
EXPERIMENTAL
▵ Safety
• Back up NAND (MAC + radio cal are unique) before any flash
• Never write ART partition or bootloader region (0x0-0x1000000)
• Never hardcode an MTD number — verify live with cat /proc/mtd
• Keep UART attached until install method is proven on your unit
